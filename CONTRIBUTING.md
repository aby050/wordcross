# Contributing to WordCross

Thanks for helping make WordCross better.

## Before you start

- **Open an issue for anything larger than a bug fix** so the approach can be agreed first.
- By contributing you agree that your contribution is licensed under the project's
  [license](LICENSE) and that the maintainer may use it in the published app.

## Principles

- **Offline and private.** No network calls, analytics, ads or sign-in. Everything works with no signal.
- **Calm.** No timers that punish, no pop-ups that interrupt a puzzle.
- **Fair puzzles.** Clues must be accurate, family-friendly and solvable without trivia.

## Development setup

```bash
npm install
npx expo start
```

`android/` and `ios/` are generated by `expo prebuild` and are not committed.

## Making a change

1. Fork the repo and branch from `main`: `fix/…`, `feat/…`, `clues/…` or `docs/…`.
2. Keep each pull request to one concern.
3. Run `npx tsc --noEmit` — it must pass with zero errors.
4. Attach screenshots for UI changes and say which device / OS you tested on.

## Code style

- TypeScript in strict mode; avoid `any`.
- Function components and hooks; game logic stays out of screen components.
- Check layouts on a small phone and a tablet.

## Commit messages

Imperative mood, describing the effect: `Fix stacked words in long levels`, not `fixed bug`.
